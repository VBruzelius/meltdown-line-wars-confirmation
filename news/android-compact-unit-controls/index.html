Compact Mobile Unit Controls

Smaller unit windows, collapsible counters and more reliable touch upgrades on phones.

Improvements

  • Unit information and upgrade choices now use compact, content-sized panels with less empty space. Tap the unit heading to expand its details.
  • Minimize unit controls without losing your selection, then reopen upgrades when you are ready. Multi Select tucks the panels away so you can select more units.
  • The Units counter is now a small expandable button beside Damage, above the battlefield. Choosing a tier closes the list.

Fixes

  • Fixed touch Multi Select mistaking an emulated mouse event for a second finger.
  • Upgrade panels now receive taps ahead of overlapping background buttons. Desktop retains its existing unit information and tier counter layout.
